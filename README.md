## 서비스 기획서: 연말 덕담 타임캡슐

### 1) 서비스 컨셉

- 누군가가 **캡슐(방)** 을 만들고 링크를 공유하면,
- 지인들이 **익명/닉네임으로 덕담**을 남김
- 오픈 방식에 따라
    - **지정 시각에 전체 공개**
    - 또는 **랜덤으로 하나씩만 열기**
- 이벤트가 끝나면 **자동으로 사라짐(만료)**

> 핵심 재미: “어떤 말이 올지 모르는 기대감” + “공개 방식(랜덤/일괄)에서 오는 게임성”
> 

---

## 2) 사용자 플로우

### (A) 캡슐 만든 사람(호스트)

1. 캡슐 만들기
    - 캡슐 제목(예: “2026 덕담함”)
    - 오픈 방식 선택
        - `ALL_AT_ONCE`: 지정 시각에 전체 공개
        - `RANDOM_ONE_BY_ONE`: 랜덤으로 한 개씩 열기
    - 오픈 시각(예: 2026-02-16 09:00 KST)
    - 작성 옵션
        - 익명 허용 on/off
        - 한 사람당 최대 작성 수(기본 1개)
2. 링크 공유
3. 오픈 시각이 되면
    - 전체 공개 or 랜덤 열기 화면으로 이동
4. (선택) 결과 이미지/카드로 공유(스크린샷 유도)

### (B) 덕담 남기는 사람(참여자)

1. 링크 접속
2. 닉네임(또는 익명) + 덕담 작성
3. 제출 후 “남겼다” 확인 화면
4. 오픈 후 다시 들어와서 확인(랜덤이면 더 긴장감)

---

## 3) 핵심 기능(8개, 깔끔하게)

1. **소셜로그인 연동 (카카오)**
2. **캡슐 생성 (편지함)**
3. **캡슐 링크 공유(키 기반)**
4. **덕담 작성(익명/닉네임) (편지)**
5. **스팸/남발 방지(간단 Rate limit + 1인 N개 제한)**
6. **오픈 상태 관리(잠김/오픈됨/만료)**
7. **전체 공개 화면**
8. **랜덤 열기(한 번에 1개, 열 때마다 누적) - 나중에**
9. **자동 만료/삭제(TTL + 상태전환)**

---

## 4) 화면 구성(최소)

- `로그인` 페이지
- `캡슐 만들기` 페이지 (편지함) ⇒ 나중에 이벤트 종류에 따라 UI 디자인 고를 수 있게
- `캡슐 참여(작성)` 페이지 (편지)
- `오픈 전 대기` 페이지 (카운트다운)
- `오픈 결과`
    - 전체 공개 뷰
    - 랜덤 열기 뷰(“열기” 버튼 → 카드 애니메이션)
- `관리(호스트용)` 페이지(선택) ⇒ 나중에
    - 남은 개수, 오픈 시간 변경(선택), 수동 만료(선택)
